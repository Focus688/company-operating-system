## What is this?

A **cross-industry, actionable framework** for running a company. It decomposes "how to run a company well, make money, and last forever" into:

- **8 layers**: Strategy → Governance → Value Chain → Organization → Resources (People/Finance/Materials/Data) → Moat → Risk & Compliance → Decision Engine
- **3 cross-cutting threads**: Time (lifecycle), People (iceberg model), Industry (differences)
- **1 decision engine**: How CEOs make correct decisions under uncertainty

Every module ships with **real cases, tools, and checklists**. No fluff, no management buzzword soup.

> We built this because GitHub has Odoo (ERP), Operately (company OS), Holacracy (governance constitution) — but **no complete cross-industry management system documentation** that connects strategy → governance → operations → resources → moat → risk → people → time → decision-making in one chain. We filled that gap.

## Quick Start

- **Are you a CEO/founder?** Start with [Decision Engine](docs/08-决策引擎-CEO决策方法论.md) + [Implementation](docs/12-落地清单-先做哪几件事.md)
- **Building a management system?** Start with [Strategy](docs/01-牵引层-战略预算考核复盘.md), go layer by layer
- **Writing a company handbook?** See [Open source tools & resources](docs/13-开源工具与参考资源.md) — 30+ handbooks from big companies

**The 6-step path to implementation** (details in [12-落地清单](docs/12-落地清单-先做哪几件事.md)):

1. 🔢 **Calculate**: real gross margin by product / customer (management accounting)
2. 📐 **Set rules**: budget + authorization & approval matrix
3. 📅 **Build rhythm**: monthly operating review + quarterly strategy review
4. 👥 **Secure key roles**: A/B backup + equity for core talent
5. 🚧 **Set red lines**: cash flow / single-customer / policy scenarios
6. 🔁 **Improve continuously**: kill one unprofitable business every year
