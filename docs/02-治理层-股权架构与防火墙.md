# 02 · 治理层：股权架构、三会一层、分子公司与防火墙

> 治理层回答：**谁说了算？风险怎么隔离？**
> 尤其跨境/外贸公司，治理结构直接决定税务合规与风险边界。

---

## 1. 股权分配

### 1.1 控制权比例

| 比例 | 含义 | 用途 |
|:---|:---|:---|
| 67%+ | 绝对控制 | 修改章程、增减资、合并分立 |
| 51%+ | 相对控制 | 大部分经营决策 |
| 34%+ | 一票否决 | 防御性持股（保护创始人） |

### 1.2 合伙人股权设计

- 出资 vs 出力：资金股 + 人力股（动态调整）
- **退出机制**：回购条款（离职/分手/死亡）
- **股权激励池**：预留 10-20% 给核心团队
- ⚠️ 代持风险：代持协议要公证 + 确权

### 1.3 三会一层

```
股东会（最高权力）→ 董事会（决策）→ 监事会（监督）→ 经理层（执行）
```

- 中小公司：董事会可精简为执行董事
- 关键：**决策权责明确到人**，避免「股东会管一切」或「经理层无人制约」

## 2. 分子公司设置 / 防火墙

### 2.1 为什么要设分子公司

| 目的 | 说明 |
|:---|:---|
| 风险隔离 | 一个主体出事不牵连全部（法律防火墙） |
| 税务优化 | 不同主体不同税率/优惠政策 |
| 业务清晰 | 不同业务线/区域独立核算 |
| 融资/上市 | 主体清晰便于资本运作 |

### 2.2 跨境/外贸公司经典结构

```
境内生产主体（成本中心）
   ↓ 转移定价（按市场价）
香港/新加坡贸易主体（利润中心/资金池）
   ↓
境外销售主体（贴近市场）
```

- 境内：生产、成本、退税
- 香港/新加坡：贸易、资金池、税务优化（利得税低）
- 境外：贴近客户、品牌、本地化

### 2.3 ⚠️ 跨境三大合规红线

1. **转移定价**：关联交易必须按市场价（OECD 独立交易原则），否则税务机关调整+罚款
2. **资金回流**：利润分红/服务费/货款三条通道，不能地下钱庄
3. **外汇管理**：用锁汇工具（远期/期权）对冲汇率风险

## 4. 案例

| 公司 | 治理安排 | 启示 |
|:---|:---|:---|
| 思摩尔国际 | 开曼上市主体+香港中间层+内地生产基地+海外销售 | 跨境隔离+资本运作标准架构 |
| 华为 | 员工持股（虚拟受限股）99%+任正非1%控制 | 控制权与激励可以分离 |
| 阿里 | 合伙人制度 | 不靠股权比例也能控制 |
| 海底捞 | 海底捞+颐海国际+蜀海分拆上市 | 业务分拆=风险隔离+资本运作 |

---

> 📌 **一句话总结**：治理层 = 控制权设计（谁说了算）+ 风险隔离（防火墙）+ 合规（转移定价/外汇/资金）。
