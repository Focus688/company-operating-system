# 03 · 横向价值链：研产供销服

> 横向看的是「价值如何被创造出来」——从客户需求到客户满意的一条流。
> 每个环节都是增值点，也是利润漏点。

---

## 价值链全景

```
市场/业务 → 研发 → PMC/工程 → 生产 → 品控 → 交付 → 客服/客诉
   │        │         │         │       │      │        │
 订单      DVT/PVT   计划/物料  量产    质量    物流仓储  闭环
```

---

## 1. 业务（目标市场与业务形态）

| 业务形态 | 毛利 | 投入 | 控制力 | 典型 |
|:---|:---|:---|:---|:---|
| 品牌 | 高 | 高（营销/渠道） | 强（掌握终端） | 苹果/老干妈/安克 |
| ODM | 中 | 中（设计+制造） | 中（绑定客户） | 思摩尔/立讯 |
| OEM | 低 | 低 | 弱（纯代工） | 富士康（部分） |

- ⚠️ 微笑曲线：研发/品牌两端利润高，制造中间薄
- ⚠️ 补漏：客户结构管理——大客户集中度、账期、信用、客户生命周期

**关键问题**：
- 我们的目标客户是谁？凭什么选我们？
- 要不要从 OEM → ODM → 品牌升级？

---

## 2. 研发（立项/设计/DVT/PVT）

```
立项评审 → 设计 → DVT（设计验证）→ PVT（量产验证）→ 量产
```

| 阶段 | 核心动作 | 关键指标 |
|:---|:---|:---|
| 立项 | 市场+技术双评审（不做伪需求） | 市场需求、ROI |
| 设计 | 结构/电子/软件/外观 | 成本预算 |
| DVT | 功能/性能/可靠性测试 | 测试通过率 |
| PVT | 试产验证工艺 | 良率、直通率 |
| 量产 | 爬坡+稳定 | 产能、成本 |

- ⚠️ 补漏：项目制管理（PM）、技术路线图、IP管理（专利+保密）、研发成本双控
- 案例：华为 IPD——研发从「英雄式」变「流程式」，三道评审关

---

## 3. PMC / 工程 / 生产（PVT→量产）

| 环节 | 职责 | 关键指标 |
|:---|:---|:---|
| PMC计划 | 订单→产能→排产 | 计划达成率 |
| PMC物料 | 齐套、库存 | 齐套率、库存周转 |
| 工程 | 工艺/设备/治具/爬坡 | 直通率 |
| 生产 | 现场/产量/良率 | 良率、OEE、产能利用率 |

**丰田精益生产（TPS）核心**：
- 准时制（JIT）：需要时刚好送到
- 看板：拉动式生产
- 安灯：一线工人可拉停产线
- Kaizen：持续改善（全员）

---

## 4. 品控

```
IQC（来料）→ IPQC（制程）→ FQC（成品）→ OQC（出货）
```

**质量成本定律**：
```
预防成本 < 检验成本 < 失败成本（返工/退货/客诉）
```

- 花 1 元做预防，省 10 元检验，省 100 元失败
- 案例：丰田安灯制度——质量优先于产量

---

## 5. 交付与售后（物流/仓储/客服）

| 环节 | 职责 | 关键指标 |
|:---|:---|:---|
| 物流（运） | 发货/运输/报关 | 准时交付率 |
| 仓储（存） | 库存/周转/呆滞 | 库存周转、呆滞率 |
| 客服 | 客诉处理/售后 | 客诉闭环时长 |

**客诉处理 8D 流程**：
1. 成立小组 → 2. 问题描述 → 3. 临时措施 → 4. 根本原因 → 5. 永久对策 → 6. 验证 → 7. 预防 → 8. 祝贺团队

- ⚠️ 补漏：售后成本计入产品毛利；客诉时效与满意度是续单的隐性指标

|:---|:---|:---|

| 丰田 | 精益生产 | 制造即护城河 |
| 立讯精密 | 紧跟大客户+工艺突破 | 绑定龙头 |
