# 08 · 决策引擎：CEO 在信息不充分/不确定下如何决策

> 决策的本质：在信息永远不充分、未来永远不确定的情况下，
> 用一套方法提高「正确率」并降低「犯错成本」。
> 这是全书唯一一个「引擎」——它驱动其他所有层。

---

## 1. 理论基础（论文/思想）

### 1.1 赫伯特·西蒙「有限理性」（诺贝尔奖）

- 人不是全知全能的，决策追求**满意解**而非**最优解**
- 做法：先定标准 → 找到第一个达标的方案就执行 → 不追求完美
- 启示：**永远等「最优方案」= 永远不决策**

### 1.2 卡尼曼「系统1/系统2」（诺贝尔奖）

- 系统1：快、直觉、自动（省力，但易错）
- 系统2：慢、理性、费力（准确，但耗能）
- 重大决策用系统2，同时警惕系统1的偏见：
  - 锚定效应（被第一个数字带偏）
  - 确认偏误（只找支持自己的证据）
  - 过度自信（高估自己判断准确率）

### 1.3 克莱因「直觉决策」RPD模型（自然决策理论）

- 专家在高压下的「直觉」= **模式识别**（来自大量经验积累）
- 新手别用直觉；老手在熟悉领域可以快
- 做法：识别情境 → 匹配模式 → 模拟推演 → 行动

### 1.4 塔勒布「反脆弱」

- 不确定下不做「预测」，做「准备」
- 保持冗余（现金/备用供应商/备用方案）
- 让波动对你有利（杠铃策略：极度保守 + 极度冒险）

### 1.5 壳牌「情景规划」（Scenario Planning）

- 不做单一预测，做 2-4 个情景（最好/最坏/基准）
- 每个情景配应对预案
- 案例：壳牌 1970s 靠情景规划预判石油危机，从行业末位跃升第一

### 1.6 任正非「灰度哲学」

- 不在非黑即白中纠结，**先走起来再校准**
- 「方向大致正确，组织充满活力」
- 允许试错、允许灰度，但不允许停滞

## 2. 可落地的决策方法：Vex 五步法

### ① 分清决策类型

**贝索斯：单向门 vs 双向门**

| 类型 | 特征 | 决策速度 |
|:---|:---|:---|
| 双向门（可逆） | 便宜、可回头 | 快（70%信息就拍板） |
| 单向门（不可逆） | 贵、难回头 | 慢（多验证、多咨询） |

- 例：换供应商（可逆）→ 快；建新工厂（不可逆）→ 慢
- ⚠️ 大多数 CEO 把可逆决策拖成不可逆的慢，把不可逆决策拍得太快

### ② 明确信息缺口

- 缺什么信息？获取成本 vs 等待成本？
- **70% 信息就决策**（贝索斯）：等100%往往错过时机
- 决策矩阵：

```
                信息充分          信息不充分
行动成本低   →  直接做            小步试
行动成本高   →  充分分析后做      情景规划+期权思维
```

### ③ 用规则对冲不确定

预设**决策原则**（情绪上来时按规则执行，不靠临场判断）：

- 「不赌单一客户」（客户集中度红线）
- 「现金流红线」（账上现金低于X个月开支不扩张）
- 「不投看不懂的领域」
- 「每笔大投入设止损线」

### ④ 小步试错 / 期权思维

把大赌注拆成**可撤销的小赌注**：

- 新市场 → 先小规模试点
- 新产品 → 先 MVP 验证
- 新客户 → 先小订单
- 验证后再放大（实物期权：买一个「未来决策的权利」，不是一次性下注）

### ⑤ 设定复盘点（贝叶斯更新）

决策时约定：**什么条件下重新评估/止损/加码**：

- 「如果3个月后新客户贡献<X，就砍掉」
- 「如果毛利率跌破X%，就涨价/换供应商」
- 新证据来了就修正判断——**不因面子、沉没成本拒绝认错**

## 3. 决策与体系其他层的衔接

```
战略定方向（01章）
  ↓
预算给资源（01章）
  ↓
决策在执行中高频发生（本层）← 需要信息管道（05章"数"）
  ↓
复盘校准（01章）→ 修正下一次决策
```

**信息管道**（决策的地基）：
- 经营驾驶舱：每日收入/毛利/现金流/库存/在制
- 管理会计：分产品/分客户/分项目的真实利润
- 例会机制：月度经营会（数据）+ 季度复盘（方向）

## 4. CEO 决策实战清单

**每次重大决策前问自己 5 问**：

1. 这是单向门还是双向门？（决定速度）
2. 我缺什么信息？值不值得等？（决定是否先收集）
3. 最坏情况是什么？我能不能承受？（决定下注大小）
4. 有没有更小、更可逆的验证方式？（决定路径）
5. 我什么时候重新评估？（决定复盘点）

**识别自己的偏见**：

- 我是不是只看了支持自己的证据？（确认偏误）
- 我是不是被第一个数字锚定了？（锚定）
- 我是不是高估了胜率？（过度自信）
- 我是不是因为已经投入太多而不肯止损？（沉没成本）

## 5. 案例库

| 公司/人 | 决策 | 方法论 | 启示 |
|:---|:---|:---|:---|
| 贝索斯 | AWS 从内部需求到对外服务 | 双向门+70%信息 | 可逆决策要快 |
| 任正非 | 灰度哲学、让听得见炮声的人呼唤炮火 | 灰度+授权 | 方向大致正确即可 |
| 王传福 | 2003年豪赌电动车 | 技术鱼池+坚定对赌 | 赌注要可承受 |
| 壳牌 | 1970s 情景规划 | 情景规划 | 不确定性靠情景不靠预测 |
| 丰田 | 遇质量问题先停产 | 安灯+暂停原则 | 规则对冲情绪 |
| 瑞幸 | 2020造假危机→快速重组 | 快速认错+重建 | 止损要果断 |
| 诺基亚 | 不转型智能机 | 沉没成本绑架 | 该砍就砍 |

---

> 📌 **一句话总结**：CEO 决策 = 分清可逆性 × 明确信息缺口 × 用规则对冲 × 小步验证 × 设复盘点。
