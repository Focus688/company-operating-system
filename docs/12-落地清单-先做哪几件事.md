# 12 · 落地清单：先做哪几件事

> 理论再好，落地才是真章。
> 这一章给出「从体系到行动」的路径：先做什么、后做什么、每月怎么诊断。

---

## 一、6步落地路线（按优先级）

### 1️⃣ 算清楚：分产品/分客户的真实毛利

**没有这个，定价和砍单都是拍脑袋。**

- 用 ERP 数据做管理会计（分产品/分客户/分项目核算）
- 找出：赚钱的20%（加大投入）、不赚钱的（涨价/砍掉）
- 产出：一页纸「产品利润表」

### 2️⃣ 定规则：预算 + 授权审批权限表

- 年度预算（收入/成本/利润目标拆到部门）
- 授权表：谁有权花多少钱（预算内自主，预算外审批）
- 产出：一页纸「授权权限表」

### 3️⃣ 建循环：月度经营分析会 + 季度复盘

- 月度经营会（雷打不动）：数据差异 → 归因 → 动作
- 季度复盘：方向校准 → 假设检验 → 目标调整
- 产出：会议日历（每月固定）

### 4️⃣ 抓关键岗位：AB角 + 核心人才绑定

- 每个关键岗位 A/B 角（不依赖单个人）
- 核心人才：股权/高薪绑定
- 产出：关键岗位清单 + 继任计划

### 5️⃣ 设红线：现金流/客户/政策预案

- 现金流红线：账上现金 < X 个月开支不扩张
- 客户红线：单一客户 > 50% 必须发展第二客户
- 政策预案：行业政策突变的情景应对（尤其电子烟）
- 产出：一页纸「红线清单」

### 6️⃣ 持续改进：每年淘汰一个不赚钱的业务

- 每年：战略复盘 → 淘汰一个不赚钱的客户/产品/业务
- 每年：护城河加宽一条
- 产出：年度战略会

## 二、每月经营诊断模板

> 每月 10 号前过一遍，10 分钟。

### 财务
- [ ] 收入 vs 预算（差异%）
- [ ] 毛利率（环比变化？）
- [ ] 现金流（未来3个月够不够？）
- [ ] 应收账期（恶化？）

### 经营
- [ ] 准时交付率（下降？）
- [ ] 库存周转（上升/呆滞？）
- [ ] 良率/直通率（异常？）
- [ ] 大客户订单（稳定？集中度？）

### 组织
- [ ] 关键岗位是否有人？（AB角）
- [ ] 核心人才流失风险？
- [ ] 本月客诉TOP3（归因/闭环？）

### 战略
- [ ] 本月市场变化？（对手/政策/需求）
- [ ] 假设是否需要修正？
- [ ] 下月TOP3 动作？

---

## 三、年度战略会模板（1天）

```
上午：回顾
├─ 去年目标达成率（差距分析）
├─ 五看（宏观/行业/客户/竞争/自己）
└─ 复盘：哪些假设错了

下午：规划
├─ 明年方向（做什么/不做什么）
├─ 三地平线（H1/H2/H3 资源分配）
├─ 预算（收入/成本/利润目标）
├─ 考核目标（公司→部门→个人）
└─ 关键动作TOP10
```

> 📌 **一句话总结**：落地 = 算清楚毛利 → 定授权规则 → 建两会循环 → 抓关键岗位 → 设红线 → 每年淘汰。每月用诊断模板过一遍，坚持一年，体系自然长出来。
