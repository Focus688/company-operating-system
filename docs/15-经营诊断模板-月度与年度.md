# 15 · 经营诊断模板：月度 + 年度

> 可下载、可打印、可填空的管理体检表。
> 用法：每月10号前过一遍月度版（10分钟）；每年12月做年度版（1天）。
> 这套模板对应全书 13 章，是「体系 → 行动」的最小闭环。

## 三、季度复盘模板（半天）

> 每季度末，1-2小时即可。

1. 本季度收入/利润 vs 预算（差异%）
2. 本季度做了什么？（关键动作回顾）
3. 市场/竞争/政策有什么变化？（假设检验）
4. 下季度TOP3 动作 + TOP3 风险
5. 战略方向是否需要修正？

## 四、快速评分卡（0-100分）

> 每年做一次，对比去年，看体系是否在长。

| 维度 | 评分项 | 0-10分 | 去年 | 今年 | 变化 |
|:---|:---|:---|:---|:---|:---|
| 战略 | 方向清晰度（做什么/不做什么） | | | | |
| 战略 | 年度战略会有没有开、开得实不实 | | | | |
| 治理 | 股权/控制权/防火墙是否清晰 | | | | |
| 经营 | 价值链各环节是否有Owner | | | | |
| 经营 | 部门墙严重度（10=没有墙） | | | | |
| 资源 | 真实毛利是否算得清（分产品/客户） | | | | |
| 资源 | 现金流管理（账期表/预测） | | | | |
| 资源 | 信息系统（ERP/驾驶舱） | | | | |
| 护城河 | 护城河宽度 vs 去年（1-10） | | | | |
| 风险 | 红线清单是否执行 | | | | |
| 风险 | 危机预案是否演练 | | | | |
| 人 | 关键岗位AB角覆盖 | | | | |
| 人 | 核心人才绑定（股权/留任） | | | | |
| 人 | 文化落地（价值观进考核） | | | | |
| 决策 | 决策机制（类型/复盘点） | | | | |
| **总分** | **（160分制 → 百分比）** | | | | |

**解读**：
- ≥80%：体系健康，持续迭代
- 60-80%：有骨架，补短板
- <60%：还在「人治」阶段，优先落地 12 章 6 步

## 五、模板使用说明

1. 打印/复制到 Excel/Notion/飞书多维表格
2. 月度版：财务负责人填A，运营填B，人事填C，CEO填D
3. 年度版：提前1周发材料，会议只做决策不做汇报
4. 所有「红灯」必须给出**动作+负责人+期限**，否则诊断是空转

> 📌 这套模板与 12 章落地清单配套使用。坚持 12 个月，体系自然长出来。
