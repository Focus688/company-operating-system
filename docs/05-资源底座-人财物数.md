# 05 · 资源底座：人、财、物、数

> 底座回答：**靠什么支撑经营？**
> 先有人，再谈事；先有数据，再谈决策。
> ⚠️ 「数」是现代企业的第四种资源，很多公司漏掉它。

---

## 1. 人（人力资源）

### 1.1 选育用留

| 环节 | 核心动作 | 关键点 |
|:---|:---|:---|
| 选 | 招聘/甄选 | 冰山之上看能力，冰山之下看价值观（见10章） |
| 育 | 培训/带教 | 能力可培养，价值观几乎不能改 |
| 用 | 岗位匹配 | 用人之长，容人之短 |
| 留 | 薪酬+成长+意义 | 钱/晋升/使命三层缺一不可 |

### 1.2 ⚠️ 补漏

- **人才梯队/继任计划**：关键岗位不能只有一个人会（AB角）
- **激励机制**：奖金/晋升双通道 + 股权（核心人才绑定）
- **绩效管理**：目标→考核→反馈→改进（闭环）

---

## 2. 财（财务/税务）

### 2.1 三大报表

| 报表 | 回答 | 关键点 |
|:---|:---|:---|
| 利润表 | 赚钱吗？ | 收入-成本=利润 |
| 资产负债表 | 家底多少？ | 资产-负债=净资产 |
| 现金流量表 | 活着吗？ | **现金是生死线** |

### 2.2 ⚠️ 现金流是制造业生死线

**利润是观点，现金是事实。**

三个账期决定生死：
```
应收账期（客户欠你多久）→ 越短越好
库存周转（货压多久）    → 越快越好
应付账期（你欠供应商多久）→ 越长越好（无息融资）
```

- 案例：很多企业死于「利润表好看但现金流断裂」
- 管理动作：账期表、催收制度、库存红线、现金流预测（未来3-6个月）

### 2.3 税务筹划（跨境尤其）

- 出口退税（制造业）
- 转移定价（关联交易按市场价）
- 香港/新加坡架构（利润留低税率地区）
- ⚠️ 不是逃税，是合规优化

---

## 3. 物（采购/供应链）

### 3.1 供应商全生命周期

```
寻源 → 认证 → 比价议价 → 下单 → 绩效评估 → 淘汰
```

| 环节 | 关键点 |
|:---|:---|
| 寻源 | 至少2-3家候选 |
| 认证 | 样品+审核+小批量 |
| 议价 | 年降、账期、批量折扣 |
| 绩效 | 质量/交期/价格/配合度打分 |
| 淘汰 | 连续不达标就换 |

### 3.2 ⚠️ 供应链韧性

- 关键物料**双源**（不赌单一供应商）
- 长周期物料提前锁定
- 断供预案（替代料/替代供应商/安全库存）
- 地缘/涨价/物流风险监控

---

## 4. 数（信息系统/数据底座）⚠️ 现代企业必备

### 4.1 系统栈

| 系统 | 解决什么 | 制造企业 |
|:---|:---|:---|
| ERP | 业财一体（订单-采购-生产-库存-财务） | 金蝶/用友/Odoo/ERPNext |
| MES | 制造执行（工单-工序-良率） | 生产现场 |
| CRM | 客户管理 | 销售 |
| WMS | 仓储管理 | 库存 |
| BI | 数据分析/驾驶舱 | 决策 |

### 4.2 经营驾驶舱（管理会计）

**分产品/分客户/分项目的真实利润** —— 定价和砍单的基础。

```
每日/每周看：
├─ 收入（分产品/客户）
├─ 毛利（分产品/客户）
├─ 现金流
├─ 库存（金额+周转）
└─ 在制订单（交付风险）
```

- 案例：很多公司「感觉赚钱」但不知道哪个产品赚钱——用 ERP 数据做管理会计立刻清楚
- ⚠️ 数据不是越多越好，是**决策要看什么就上什么**

---

## 5. 成本结构（人/财/物占比）

| 行业 | 典型成本结构 |
|:---|:---|
| 制造业 | 料50-70% + 工10-20% + 费20-30% |
| 服务业 | 人力60%+ |
| 贸易 | 货+运费+资金成本 |
| 软件 | 人力60-80% + 云 |

- 管理动作：作业成本法算真实成本 → 定价/砍单有据

---

> 📌 **一句话总结**：底座四资源——人（选育用留）、财（三表+现金流）、物（供应链）、数（系统+驾驶舱）。现金流和真实毛利是制造企业的两条命脉。
