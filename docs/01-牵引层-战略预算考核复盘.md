# 01 · 牵引层：战略 → 预算 → 考核 → 复盘

> 宏观循环：决定公司「往哪走、怎么分配资源、怎么纠偏」。
> 这是公司所有管理动作的「方向盘」。

---

## 1. 战略（方向）

### 1.1 方向：做什么、不做什么

战略第一件事是**取舍**。不是「什么赚钱做什么」，而是「我们是谁、服务谁、不服务谁」。

- **聚焦原则**：把一个细分市场做深，胜过十个市场做浅
- **砍单原则**：不赚钱的客户/产品/业务，果断砍（每年至少砍一个）
- 案例：**老干妈**——只做辣酱，不融资、不上市、不扩张品类，一瓶辣酱做到百亿

### 1.2 竞争对手分析（波特五力）

| 五力 | 核心问题 | 应对动作 |
|:---|:---|:---|
| 现有竞争者 | 竞争激烈程度？ | 差异化/成本领先 |
| 潜在进入者 | 新玩家威胁？ | 提高进入壁垒（牌照/专利/规模） |
| 替代品 | 有没有替代方案？ | 绑定客户转换成本 |
| 供应商议价 | 上游多强势？ | 多源/纵向整合/长协 |
| 买方议价 | 客户多强势？ | 分散客户/品牌溢价 |

### 1.3 未来变量 / 不变

- **识别变量**：技术、政策、需求、竞争格局哪些会变？
- **押注不变**：把资源押在「十年不变的东西」上
  - 案例：**亚马逊**押「客户永远要低价/快/多选」；**比亚迪**押「电动化趋势」
  - 反例：诺基亚押「手机通话」，没看到「智能+生态」

### 1.4 对赌或博弈

战略本质是**与市场对赌**：你赌一个方向，市场会给反馈。

- 关键：**赌注要可承受**——输了不致命，赢了有巨大回报（期权思维，见 08 章）
- 节奏：什么时候进攻（窗口期）、什么时候防守（逆风期）

## 2. 预算（资源的分配）

预算是**战略的数字化**，不是财务部的事。

- 收入/成本/利润目标 → 拆到部门/产品/客户
- **预算 = 授权**：预算内部门自主决策，预算外走审批（放权与控制的平衡点）
- 制造业注意：预算要拆到 BOM 成本、人工工时、制造费用
- 案例：华为「三年滚动预算」+「以项目为单位核算」

---

## 3. 考核（各层抓执行）

公司 → 部门 → 个人，目标层层拆解：

- **KPI**（结果导向）：销售收入、毛利率、准时交付率、良率
- **OKR**（过程+野心）：挑战性目标 + 关键结果
- 考核必须**与激励挂钩**（奖金/晋升/股权），否则空转

**KPI 树**（源自 BIZOS 的设计思路，可直接套用）：

```
公司层：净利润 = 收入 − 成本
├─ 收入：销售额 × 毛利率
│   ├─ 新客户收入 / 老客户复购
│   └─ 产品线A/B/C 各自贡献
├─ 成本：料（BOM成本）× 工（人工效率）× 费（制造费用）
│   ├─ 采购降本率
│   ├─ 生产良率 / 直通率
│   └─ 库存周转率
└─ 现金流：应收账期 × 库存周转 × 应付账期
```

## 4. 复盘（校准方向的机制）

| 频率 | 会议 | 内容 |
|:---|:---|:---|
| 月度 | 经营分析会 | 数据差异：收入/毛利/现金流 vs 预算 |
| 季度 | 战略复盘 | 方向校准：市场变化、竞争动态、假设检验 |
| 年度 | 战略规划会 | 重定规划、预算、考核目标 |

**复盘三问**（不是追责，是校准）：
1. 目标达成了吗？（差距多大）
2. 为什么？（归因：市场/执行/假设错）
3. 下一步怎么改？（动作/资源/目标调整）

## 5. 进阶：华为 BLM 战略管理体系（DSTE/BEM/PBC）

> 华为的整套战略方法论，GitHub 有开源 skill（chinaonlineNIU/huawei-blm-strategy），本文是核心提炼。

**核心公式**：卓越绩效 = 优秀的战略设计（50%）× 有效的执行能力（50%）

**BLM 模型**：

| 维度 | 构成 | 核心问题 |
|:---|:---|:---|
| 战略（左脑） | 市场洞察、战略意图、创新焦点、业务设计 | 做什么？去哪竞争？ |
| 执行（右脑） | 关键任务、正式组织、人才、氛围文化 | 怎么做？怎么落地？ |
| 贯穿基座 | 领导力、价值观 | 谁推动？遵循什么？ |
| 闭环 | 市场结果 → 新差距 → 下一轮 | 结果如何？怎么优化？ |

**战略是由「不满意」激发的闭环**：
- **业绩差距**：现有结果 vs 期望 → 提升执行力填补
- **机会差距**：现有结果 vs 新业务可能性 → 必须设计新模式捕捉

**五看模型**（市场洞察）：

| 五看 | 内容 | 工具 |
|:---|:---|:---|
| 看宏观 | 政策/经济/社会/技术 | PEST |
| 看行业 | 规模/增长/格局 | 波特五力、SPAN矩阵 |
| 看客户 | 需求/痛点/采购行为 | 客户场景还原法 |
| 看竞争 | 对手战略/优劣/动向 | 竞争对标 |
| 看自己 | 能力/资源/短板 | 内部能力评估 |

**三成长地平线**：

| 地平线 | 业务 | 资源 | 衡量 |
|:---|:---|:---|:---|
| H1 | 核心业务 | 70% | 收入/利润/份额 |
| H2 | 成长业务 | 20% | 增长/新市场 |
| H3 | 新兴机会 | 10% | 用户/生态 |

**双轨目标法**：必达目标（≥90%完成率）+ 挑战目标（≈50%完成率）

**BEM 解码链**：战略 → CSFs（关键成功因素）→ KPI → 重点工作 → PBC（个人绩效承诺）

> 💡 **落地建议**：中小公司不需要完整照搬华为，但「五看 + 三地平线 + 双轨目标 + 季度复盘」这套骨架可以直接用。

## 案例汇总

| 公司 | 做法 | 启示 |
|:---|:---|:---|
| 华为 | BLM/DSTE/BEM 全套闭环 | 战略是制度化的自我批判 |
| 亚马逊 | 押不变（低价/快/多选） | 资源押在不变上 |
| 比亚迪 | 技术鱼池 + 电动化对赌 | 赌注可承受、方向坚定 |
| 老干妈 | 聚焦不扩张 | 取舍就是战略 |
| 诺基亚 | 没看见智能机 | 不变的是用户需求，不是产品形态 |
