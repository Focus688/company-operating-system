## 这是什么？ / What is this?

一套**跨行业、可落地**的公司管理系统框架。不是 ERP 软件，不是管理鸡汤，而是把「一家公司怎么管好、怎么赚钱、怎么基业长青」拆解成**八层结构 + 三大贯穿线 + 一个决策引擎**的完整体系，每个模块配案例、配工具、配落地清单。

A cross-industry, actionable framework for running a company. Not ERP software, not management fluff — a complete system decomposed into **8 layers + 3 cross-cutting threads + 1 decision engine**, with cases, tools, and checklists for every module.

> **中文版为主，英文摘要为辅。** 欢迎 PR 补充更多行业案例。

## 快速上手 / Quick Start

**如果你是老板/CEO**：先读 [08-决策引擎](docs/08-决策引擎-CEO决策方法论.md) + [12-落地清单](docs/12-落地清单-先做哪几件事.md)。

**如果你在搭建管理体系**：从 [01-牵引层](docs/01-牵引层-战略预算考核复盘.md) 开始，逐层过。

**如果你在写公司手册**：看 [13-开源工具与参考资源](docs/13-开源工具与参考资源.md)，30+ 大厂 handbook 抄作业。

**落地六步**（详见 [12-落地清单](docs/12-落地清单-先做哪几件事.md)）：
1. 🔢 算清楚：分产品/分客户的真实毛利
2. 📐 定规则：预算 + 授权审批权限表
3. 📅 建循环：月度经营分析会 + 季度复盘
4. 👥 抓关键岗位：AB角 + 核心人才股权绑定
5. 🚧 设红线：现金流/单一客户/政策情景预案
6. 🔁 持续改进：每年淘汰一个不赚钱的业务
