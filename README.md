## 这是什么？ / What is this?

这是一个**文档化的公司经营框架**：它不处理记账、库存和订单交易，而是帮助你决定公司应该如何分层管理、如何分配资源、如何建立经营节奏，以及如何在不确定性下做决策。它可以与 ERP、项目管理工具和知识库配合使用。

不是 ERP 软件，不是管理口号，而是案例、模板和清单构成的可落地框架。

---

## 为什么做这个？ / Why?

现有开源项目通常分别解决某一层——ERP 交易、团队执行或治理制度。本项目尝试把战略、治理、价值链、资源、风险、人才和决策放进同一套跨行业经营框架。

> 中文版为主，英文摘要为辅。欢迎通过 [贡献指南](CONTRIBUTING.md) 补充行业案例、方法论、工具评测、失败案例或英文翻译。

## FAQ

**这是软件吗？**
不是。这是开源的公司经营框架、模板和诊断工具，可与 ERP、项目管理工具和知识库配合使用。

**适合什么人？**
适合创始人、CEO、经营负责人，以及正在搭建或修复管理体系的团队。

**小公司也能用吗？**
可以。先从真实毛利、授权规则、关键岗位和月度经营会开始。

**和 ERP 的关系是什么？**
ERP 记录业务交易；本项目帮助你设计经营规则、管理节奏和决策机制。
